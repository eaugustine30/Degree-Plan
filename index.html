Update this page from this device

Checking items off saves them to your repository on GitHub, so everyone with the link sees them. This needs a GitHub token that can write to that one repository. It stays on this device.

  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Expiration: pick a date after Dec 18, 2026. Repository access: Only select repositories, then this repository.
  3. Repository permissions: Contents → Read and write. Generate, then copy the token.
